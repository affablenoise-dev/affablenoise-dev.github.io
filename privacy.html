Privacy Policy

Last updated: 2026-09-21

Application scope

Workout Playlist Curator is a personal-use application operated solely for its owner. It is not provided to the public or to third-party users.

Google / YouTube data accessed

This application uses YouTube API Services. Use of Google data is also subject to the Google Privacy Policy.

The application may access the owner's YouTube subscriptions, channel and video metadata, and playlist contents. It may add selected videos to a dedicated private playlist owned by the same user.

Purpose of use

The data is used only to discover workout-related videos, avoid duplicate additions, maintain local processing state, and update the owner's workout playlist.

Storage and processing

OAuth credentials and application state are stored locally on the owner's computer. The application does not operate a separate remote user database.

Sharing and sale

The application does not sell Google user data and does not share Google user data with third parties.

Retention and deletion

Local credentials and state are retained only for continued operation of the application and can be deleted by the owner at any time. Google/YouTube API access can be revoked at any time from the Google Account third-party connections page.
